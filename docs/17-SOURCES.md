# منابع و منشأ تصمیم‌ها

## نیازمندی‌های کارفرما

- پیام اولیهٔ کارفرما شامل نقشهٔ تقریبی، حساب با username، گروه/چت، نام‌گذاری گربه، دامپزشکی، فوریت، حمایت مالی، شبکهٔ اجتماعی، ویزیت عمومی/خصوصی، نقش داوطلب، سرپرستی، مأموریت، فاکتور، مشاوره با رضایت و تقویم.
- فایل متنی گفت‌وگوی قبلی، به‌صورت بدون تغییر در [prior-chat.txt](../references/prior-chat.txt).
- درخواست بعدی برای Next.js، MVI، component-based، بررسی نواقص و تصویر صفحهٔ اول.
- درخواست فعلی برای بستهٔ Markdown، TASKS/BRD/PRD، تصویر، ZIP، همکاری Codex و Claude و زمان ساخت.

لینک اشتراک اولیه توسط ابزار وب قابل بازیابی نبود؛ متن فایل ارسالی کارفرما خوانده شد. عنوان منابع پزشکی داخل متن قبلی به معنی بررسی مستقیم آن منابع در این بسته نیست.

## مرجع فنی بررسی‌شده

- [Next.js App Router](https://nextjs.org/docs/app)
- [Server and Client Components](https://nextjs.org/docs/app/getting-started/server-and-client-components)

این منابع برای مرز Server/Client و ساختار App Router استفاده شده‌اند. انتخاب ابزارهای دیگر و برآوردها پیشنهاد طراحی هستند. هنگام شروع ساخت باید نسخه و API کتابخانه‌ها از مستندات رسمی همان نسخه بررسی شود.

## تصویر

تصویر با ابزار داخلی imagegen در همین گفت‌وگو تولید شده است. نمای مفهومی و دادهٔ ساختگی دارد. [شرح دقیق تولید](../assets/IMAGE-PROMPT.md) و PNG در assets قرار دارند. تصویر screenshot برنامهٔ ساخته‌شده نیست.

## پوشش و محدودیت

بازبینی این بسته شامل انسجام فایل‌ها، ردیابی نیازها، وابستگی تسک‌ها، وجود تصویر و صحت ZIP است. آزمون کد یا محصول هنوز موضوعیت نداشته و انجام نشده است. برآوردها در ESTIMATE فرض‌های ظرفیت و دامنه دارند. سیاست پزشکی، حقوقی و مالی نهایی وابسته به کشور و مسئولان منتخب است.
