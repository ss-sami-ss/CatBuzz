# PRD — تعریف محصول و نیازمندی‌ها

## کاربران و مسیر اصلی

بازدید نقشه → انتخاب محدوده → مشاهدهٔ گربه یا کلونی → بررسی آخرین مشاهده و نیاز → انتخاب نوع کمک → پذیرش مأموریت یا حمایت → ثبت نتیجه → پیگیری بعدی.

بازدید عمومی به ثبت‌نام وابسته نیست. اقدام دارای مسئولیت نیازمند حساب فعال است. دسترسی به درمان، موقعیت دقیق، اسناد و پرداخت بر اساس policy سرور تعیین می‌شود.

| ID | معیار مهندسی پیشنهادی |
|---|---|

| N10 | فایل‌ها محدودیت نوع/حجم، قرنطینه و پردازش داشته باشند؛ خطای آپلود قابل بازیابی باشد |
| N11 | تمام mutationها اعتبارسنجی سرور و مجوز سطح منبع داشته باشند |
| N12 | صفحهٔ خطا، loading، empty، offline و retry برای جریان‌های اصلی طراحی و آزمون شود |

## معیار خروج از پایلوت

تمام نیازهای P1، تست‌های بحرانی QA و سناریوی واقعی ثبت گربه تا بستن مأموریت در staging و محدودهٔ آزمایشی تأیید شوند. ناظر و مسیر پاسخ اضطراری تعریف شده باشد. اگر پرداخت غیرفعال است، محصول و گزارش تحویل این محدودیت را آشکار نشان دهند. این وضعیت به معنی اتمام R10 یا R14 نیست.

## معیار تکمیل محصول درخواستی

R01 تا R22 و بخش‌های P2 از R23 تا R29 مطابق جدول اجرا و تأیید شوند. تمام موارد P2، به‌ویژه مشاورهٔ دامپزشکی عمومی، ویزیت خصوصی، شبکهٔ اجتماعی و نظرسنجی نام، باید در گزارش نهایی ردیابی شوند. P3 بک‌لاگ پیشنهادی مستقل است.
